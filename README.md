# kiwi-app

The Android app of the Kiwi Network: what the control page and the kiwi-server desktop app do,
from a phone. It is a front end for the network's control node.

So far it is a skeleton: the theme, the bottom bar and four empty screens.

## Build

    ./gradlew assembleDebug lint test

Needs JDK 17 or newer and the Android SDK (platform 37).
